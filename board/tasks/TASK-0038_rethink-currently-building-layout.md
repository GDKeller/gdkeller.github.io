# Rethink the Currently Building section layout

[CurrentlyBuilding.astro](src/components/CurrentlyBuilding.astro) is built for exploration: one entry in focus at a time. It lacks the "wow" factor of seeing everything at once.

## Directions

- **Keep exploration.** Refine the current interaction so it lands harder.
- **Show everything.** Lay out all entries at once for immediate impact.
- **Hybrid.** All entries visible, with one expandable for depth.

## Acceptance

- A direction is chosen and built.
- Visually verified from 320px through 1920px.
